## 什么是模版测试

* 模版测试类似于深度测试，不过其对象是一个名为模版缓冲区（Stencil Buffer）的缓冲区，里面为每个片元存储了0~255（8bit，默认为0）的数字。
* 模版测试可以自定义一些比较规则，根据模版值来决定一些片元是否被更新（剔除或保留）。

## 什么时候进行模版测试

模版测试发生在光栅化阶段，是对逐片元进行操作。

## 如何进行模版测试

模版测试的代码可以位于Pass中也可位于Pass外。

一个完整的Stencil Test包括下面内容

```HLSL
Stencil
{
  Ref referenceValue
  ReadMask readMask
  WriteMask writeMask
  Comp comparionFunction
  Pass stencilOperation
  Fail stencilOperation
  ZFail stencilOperation
}
```

* Ref：当前片元的参考值（默认为0）
* ReadMask：读掩码
* WriteMask：写掩码
* Comp：比较操作函数
* Pass：更新操作（成功通过Comp后执行）
* Fail：更新操作（失败通过Comp后执行）
* ZFail：更新操作（模版测试通过而深度测试未通过执行）

> 更多的操作可以查看：[ShaderLab 命令：模板 - Unity 手册](https://docs.unity3d.com/cn/2022.2/Manual/SL-Stencil.html)

### ComparionFunction

![](/img/技美百人计划-模板测试/1741090533037.png)

Comp操作值定义了一系列比较行为以及是否通过测试。

### StencilOperation

![](/img/技美百人计划-模板测试/1741090544726.png)

Stencil操作值定义了一系列模版值在Comp后可以进行的操作。

### 在Shader中的使用

```
Shader "Examples/CommandExample"
{
    SubShader
    {
         // 此处是定义子着色器的代码的其余部分。

        Pass
        {  
             // 此通道中的所有像素都会通过模板测试并将值 2 写入模板缓冲区
             // 如果要防止后续着色器绘制到渲染目标的此区域或将它们限制为仅渲染到此区域，则通常会执行此操作
             Stencil
             {
                 Ref 2
                 Comp Always
                 Pass Replace
             }  

             // 此处是定义通道的代码的其余部分。
        }
    }
}
```

## 具体应用

蒙版测试可以应用于多个地方，比如描边、多边形填充、反射区域控制、阴影渲染
